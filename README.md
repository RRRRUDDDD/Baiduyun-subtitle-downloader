# 百度网盘智能字幕下载

自用脚本，将百度网盘生成的字幕保存为本地的 srt 字幕文件。

支持单个视频下载和整个文件夹批量提取，不需要播放视频，直接调用网盘字幕接口。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)；
2. 新建用户脚本，粘贴 `百度网盘智能字幕下载.user.js` 的内容并保存；
3. 打开并登录 `pan.baidu.com`。

## 使用

入口按钮会跟随网盘界面出现：

- **文件夹页**：「新建笔记」右侧的「字幕」；
- **视频播放页**：播放器工具栏「下载」右侧的「字幕」；
- 找不到网盘工具栏时，会在右下角显示一个悬浮按钮。

打开面板后，根据当前页面显示对应操作：

- **视频播放页**：点「下载本视频字幕」，保存当前视频的字幕。
- **文件夹页**：点「批量下载字幕」，自动读取当前文件夹中的视频并逐个提取字幕。

批量下载时：

- 进度条会实时显示成功、无字幕、失败的数量；
- 可以随时取消，已保存的文件会保留；
- 结束后可以「复制问题项」，把无字幕或失败的视频列表复制出来。

> 仅处理当前文件夹，不会递归子文件夹。

## 保存位置

默认保存到浏览器下载目录下的 `百度网盘字幕/<文件夹名>/`，不会弹出另存为窗口，也不会打开文件管理器。

点击面板中的「选择文件夹」可以用系统文件夹选择器指定任意目录：

- 选定后字幕会直接写入该文件夹，不再经过浏览器下载；
- 目录会保存在浏览器中，下次打开自动恢复；
- 浏览器重启后首次写入时，系统会再次请求该文件夹的访问权限；
- 点击「恢复默认」可以切回下载目录；
- 出于浏览器隐私限制，面板只能显示文件夹名称，无法显示完整路径；
- 自定义文件夹时，字幕直接平铺保存在所选目录中。

选择文件夹需要 Chrome / Edge 等支持 File System Access API 的浏览器。

无 Tampermonkey（没有 `GM_download`）且未选择自定义文件夹时，批量下载会打包成一个 ZIP。

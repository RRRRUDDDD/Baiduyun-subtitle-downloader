# 百度网盘智能字幕下载

自用脚本，把百度网盘生成的智能字幕、文稿、课件和 AI 笔记导出到本地。

| 类型 | 格式 | 内容 |
| --- | --- | --- |
| 字幕 | `.srt` | 网盘原始智能字幕 |
| 文稿 | `.txt` | 由字幕合并、整理成的纯文本，按停顿分段 |
| 课件 | `.pdf` | 网盘课件截图合成 PDF，每页带时间戳书签 |
| 笔记 | `.md` | AI 图文笔记，保留标题、列表、表格，图片尽量内联 |

支持单个视频导出，也支持当前文件夹批量处理。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)；
2. 新建用户脚本，粘贴 `百度网盘智能字幕下载.user.js` 的内容并保存；
3. 打开并登录 `pan.baidu.com`。

脚本需要 `GM_download` 和 `GM_xmlhttpRequest` 权限。后者用于下载网盘缩略图等不带 CORS 头的资源。

## 使用

入口按钮会跟随网盘界面出现：

- **文件夹页**：「新建笔记」右侧的「字幕」；
- **视频播放页**：播放器工具栏「下载」右侧的「字幕」；
- 网盘工具栏收起了「新建笔记」或找不到入口时，右下角会出现悬浮按钮。

打开面板后先勾选要导出的内容（字幕 / 文稿 / 课件 / 笔记），选择会保存在浏览器里。

- **视频播放页**：点「下载本视频字幕」或「导出所选内容」，处理当前视频。
- **文件夹页**：点「批量下载字幕」或「批量导出所选内容」，自动读取当前文件夹中的视频并逐个处理。

批量处理时：

- 进度条实时显示已完成数量和成功、跳过、失败统计；
- 可以随时取消，已保存的文件会保留；
- 单个视频缺少笔记或课件时记为「无笔记」「无课件」，不影响其它内容；
- 结束后可以「复制问题项」，把无内容或失败的视频列表复制出来。

> 仅处理当前文件夹，不会递归子文件夹。

## 导出说明

- **文稿**由字幕整理而来，因此没有智能字幕的视频也不会有文稿。
- **课件**按网盘返回的截图顺序重建 PDF，书签为「第 N 页 + 视频时间」。
- **笔记**的图片会尽量下载并内联为 data URI，保证 Markdown 单文件长期可用；个别图片下载失败时保留原始链接。网盘图片链接通常只有 8 小时有效期。
- 笔记图片内联后文件可能达到数 MB，属于正常现象。
- 无字幕、无文稿、无课件、无笔记都会在面板日志中列出，不计为失败。

## 保存位置

默认保存到浏览器下载目录下的 `百度网盘字幕/<文件夹名>/`，不会弹出另存为窗口，也不会打开文件管理器。

点击面板中的「选择文件夹」可以用系统文件夹选择器指定任意目录：

- 选定后文件直接写入该文件夹，不再经过浏览器下载；
- 目录会保存在浏览器中，下次打开自动恢复；
- 浏览器重启后首次写入时，系统会再次请求该文件夹的访问权限；
- 点击「恢复默认」可以切回下载目录；
- 出于浏览器隐私限制，面板只能显示文件夹名称，无法显示完整路径；
- 自定义文件夹时，所有文件平铺保存在所选目录中。

选择文件夹需要 Chrome / Edge 等支持 File System Access API 的浏览器。

无 `GM_download`（未使用脚本管理器）且未选择自定义文件夹时，单个文件直接交给浏览器下载；多个文件或批量导出会打包成一个 ZIP：

- 只选了字幕：`<名称>_字幕.zip`
- 选择了其它内容：`<名称>_资料.zip`

## 限制

- 仅处理当前文件夹，不递归子文件夹；
- 课件和笔记依赖网盘已经生成对应内容；
- 依赖网盘的未公开接口，接口调整后可能需要更新脚本；
- 批量默认同时处理 3 个视频，笔记编辑器会串行加载以避免网盘限流；
- 长视频的课件和笔记读取可能需要等待数十秒，面板会显示当前进度。
